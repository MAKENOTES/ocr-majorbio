# OCR 项目方案（初始版）

## 1. 目标与范围
- 目标：构建可训练、可落地的 PyTorch OCR 方案，支持扫描 PDF / 图片型 PDF。
- 方案特征：两阶段（检测 + 识别），训练更稳、可分别微调。
- 输出形式：结构化 JSON，包含页码、文字框位置、文本、置信度。

## 2. 端到端流程
1) PDF -> 页面图（渲染）
2) Text Detection（检测）：输出文字块/词/行的 bbox
3) Text Recognition（识别）：对每个 bbox crop 进行 CTC 识别
4) 结构化输出：排序、合并、导出 JSON

## 3. Detection 阶段（初始要求）
- 目标：检测文字块/词/行位置，输出 bbox。
- 标注格式：ICDAR Localization（四点 polygon + 可选文本）。
- 数据：可使用公开检测数据 + 领域微调。

## 4. Recognition 阶段（初始要求）
- 模型：CRNN（CNN + BiLSTM + CTC）。
- 输入：检测框裁剪得到的行图像。
- 输出：行文本 + 置信度。

## 5. 数据与训练建议（初始）
- 检测：行级框优先，降低标注成本。
- 识别：从检测框裁剪生成训练数据。
- 字符集：中文 + 英文 + 数字 + 常用符号。

## 6. 输出规范（初始）
- JSON 字段：page, bbox, text, score。
- 阅读顺序：按 y 再 x 排序。
